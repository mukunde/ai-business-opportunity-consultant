# Appflow v1

## Primary Flow

1. User creates an opportunity.
2. User submits an initial idea or problem statement.
3. The system runs intake and context discovery.
4. The adaptive interview asks follow-up questions.
5. The system structures the opportunity.
6. The scoring engine evaluates ROI, ICE, feasibility, risk, and alignment.
7. The recommendation engine returns proceed, do not proceed, or defer.
8. The user reviews and exports the report.

## Key States

- Draft opportunity
- Interview in progress
- Insufficient context
- Ready for scoring
- Recommendation generated
- Archived or superseded
